# Mockup A (chosen 5 Oct 2026)

Reference for the redesign of this site: the "Refined index" layout in Swiss red, matching nipunbatra.github.io.
Open `a-home.html`, `a-lectures.html`, `a-assessment.html` and `a-assignment.html` in a browser.
`build.py` generated them from `lectures.json` (extracted from `schedule.qmd`). `dl.css` and `dl.js` hold the shared styles,
the sun/moon switch, copy-link anchors and the resource icons (`ICONS` in build.py).

Decisions: no latest-lecture block on Home; keep the "Coming up" box; one icon per resource type with a key on Lectures.
This folder is a design reference and should be removed once the site implements it.
